# Ledgerly — Business Finance Dashboard

A responsive business finance dashboard demo for freelancers and small businesses, built with HTML, CSS, and vanilla JavaScript.

## Run the app

Keep `index.html`, `styles.css`, and `app.js` in the same folder. Open `index.html` in a web browser. The demo saves changes in the browser's local storage.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, and `app.js` to the top level of a GitHub repository. You may upload this README too, but it is optional.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch and the `/ (root)` folder, then save.
5. Open the website link GitHub displays in Pages settings.

## Features

- Dashboard summary for projects, tasks, invoices, income, expenses, and estimated profit.
- Client and project management.
- Invoice creation, payment status, overdue flags, and print/save as PDF.
- Income and expense tracking and printable reports.
- Cash-flow chart, hourly/day rate calculator, and a transparent educational loan readiness estimate.
- Sample data and browser local storage.

## Notes

Data is stored in the current browser only and is not synced to a server. PDF downloads use the browser print dialog; select **Save as PDF**. Loan readiness is an illustrative estimate, not a bank decision or loan offer.
